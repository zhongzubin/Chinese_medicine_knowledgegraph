本文记录 P5.1 v1 的实现结果、已验证范围和当前验收缺口。

## 1. 实现结果

主图已从 17 个固定节点调整为 14 个父图节点加 1 个检索子图入口。检索子图内部包含：

```text
plan_cypher
  -> validate_cypher
  -> execute_cypher
  -> retrieve_observe
       -> replan
       -> answer_from_graph
       -> no_evidence
       -> safe_fail
       -> finish
```

关键实现：

- 新增独立 `build_retrieval_subgraph` 构建器。
- 父图只调用编译后的检索子图，不再直接声明四个内部节点。
- 子图内部继续执行最多三次受控规划/观察循环。
- Guard、Schema、`EXPLAIN`、只读仓储和回答审核边界未改变。
- 子图内部阶段继续以原名称通过 SSE 公开。
- 父图不产生额外 `retrieval_subgraph` 公开阶段。
- 父子图之间通过显式增量函数合并状态，避免阶段耗时和轨迹重复。
- API、SSE、CLI 和公开响应字段未改变。
