## 3. 交互与安全

- SSE 使用 POST `fetch` 和 `ReadableStream`，不使用浏览器 `EventSource`。
- 匿名会话依赖同源 HttpOnly Cookie，前端不接触静态 API Key。
- 回答使用纯文本 `white-space: pre-wrap` 渲染，不执行 HTML。
- 关系、属性、统计和路径均来自结构化证据 DTO。
- 来源为 `null` 时显示“当前图谱未提供出处”。
- 审核回退或网络失败时显示明确状态。
- “新建会话”会调用 `DELETE /api/v2/session` 并清空输入、阶段、回答和证据。
- 网络断开时保留当前问题并显示稳定 `NETWORK_ERROR`。
