# 专业问答质量 v1 首轮实现与验收记录

> 验收完成：2026-10-31
>
> 对应规划：[product-quality-roadmap.md](product-quality-roadmap.md)
>
> 范围：属性证据、确定性查询模板、多轮上下文、答案支持校验

## 1. 实现范围

本轮完成：

- 新增 `AttributeFact` 属性事实模型和 `GraphQAResponse.facts`。
- 新增 `facts` SSE 事件，Streamlit 增加“图谱属性”展示区。
- 属性查询使用固定 Cypher 模板和白名单字段，不接受模型任意属性查询。
- 查询规划顺序调整为：属性模板 → 唯一关系模板 → Schema 约束 Text2Cypher。
- 支持高频正向和反向关系模板，包括组成、功效、主治、症状、疾病和来源。
- 关系证据按同一三元组合并多个来源，避免重复展示。
- 图谱回答生成后执行证据支持检查；不支持本轮证据的模型文本替换为证据化回答。
- 新会话在首次请求前创建空历史；失败轮次不写入历史，但会话仍可继续使用。
- 显式新实体直接切换主题；指代和省略追问才执行上下文改写。
- 增加 10 条属性产品集和 20 组、60 轮多轮固定集。

本轮未完成：

- 基础聚合查询和复杂多跳查询。
- 200 条以上产品级固定集。
- 独立事实验证 Agent 或人工领域专家大规模验收。
- P4 独立 Agent 拓扑。

## 7. 当前结论

专业问答质量 v1 的首轮闭环已经可用：

- 图谱属性不再被产品层遗漏。
- 高频基础问题不再依赖模型随机生成 Cypher。
- 多轮上下文通过 60 轮真实评测。
- grounded 回答具有属性或关系证据。
- 失败轮次可以恢复，不产生不可用会话。

当前仍不能宣称：

- 已支持全部中医药开放问题。
- 已完成临床级事实审核。
- 已覆盖聚合、多跳和复杂比较问题。
- 已具备 200 条以上独立产品评测结论。

下一轮应优先扩充真实问题集、聚合/多跳查询和答案事实性人工抽检，再评估独立 Agent 拓扑。
