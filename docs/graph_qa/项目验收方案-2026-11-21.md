## 1. 验收目标

验证系统是否达到：

- 可公开访问的 Vue 演示工作台。
- 可追溯的图谱问答。
- 可交互的图谱探索。
- 可核验的实体对比与报告。
- 可调用的 Tool、Skill 和本地 MCP。
- 现有安全和质量能力不回归。

验收不以页面“看起来完成”为标准，而以真实链路、结构化证据、异常处理和可重复验证为准。

### 2.3 演示环境

- 单 worker API。
- Vue 静态资源。

## 4. 发布门禁

### G0：需求与架构冻结

必须满足：

- 需求、架构、迁移和验收文档评审通过。
- Vue 3、Tool、Skill 和 stdio MCP 范围明确。
- 非目标清晰。

### G1：后端与契约

必须满足：

- 现有 pytest 全量通过。
- `/api/v1` 核心契约不回归。
- `/api/v2` 契约测试和 OpenAPI 生成通过。
- Tool 输入输出、超时和错误测试通过。
- EntityId 稳定且同名不同标签不冲突。

阻断条件：

- 任意 Tool 能提交原始 Cypher。
- V2 绕过 Guard 或证据审核。
- 前端能从响应获取密钥。

### G2：前端核心页面

必须满足：

- 证据问答、图谱探索、实体对比和审核页面可操作。
- 加载、空、错误、无证据和来源缺失状态完整。
- 手机和桌面布局通过浏览器测试。
- 浏览器中不存在模型或数据库凭据。

阻断条件：

- 关键页面只在桌面可用。
- 图谱探索渲染完整图或递归失控。
- 回答与证据无法联动。

### G3：Skill 与 MCP

必须满足：

- 三个 Skill 使用白名单 Tool。
- Skill 达到调用次数或超时后安全终止。
- stdio MCP 客户端可以发现 Resources 和 Tools。
- MCP 返回结构与 Web API 证据语义一致。

阻断条件：

- MCP 直接连接 Neo4j。
- Skill 可以调用未声明的 Tool。
- MCP 暴露任意 Cypher。

### G4：演示部署

必须满足：

- 公网 HTTPS 链接可访问。
- 只有 80/443 对外。
- 匿名会话、限流和每日预算有效。
- 健康检查、日志和自动重启有效。
- 24 小时连续运行无崩溃。

阻断条件：

- 数据库或模型密钥进入前端构建产物。
- API、Redis 或 Neo4j 端口直接暴露公网。
- 无总预算限制。

### G5：质量签收

必须满足：

- 固定演示问题全部通过。
- 未知实体、无证据和来源缺失场景全部通过。
- 现有质量指标无不可接受回归。
- 50 条人工事实审核完成并达到门槛。
- 外部模型失败时固定演示场景仍可运行。

## 5. 功能验收用例

### 5.1 证据问答

| 编号 | 输入/操作 | 预期 |
| --- | --- | --- |
| QA-01 | 询问麻黄功效 | 返回回答、属性或关系证据、来源状态和审核 |
| QA-02 | 询问含麻黄方剂 | 返回关系列表和逐项证据 |
| QA-03 | 询问动态多跳问题 | 返回完整 2～3 步路径和逐跳证据 |
| QA-04 | 多轮追问“它有什么禁忌” | 正确继承上一实体 |
| QA-05 | 询问未知实体 | 请求补充，不执行无依据查询 |
| QA-06 | 已知实体但无证据 | 明确说明图谱无依据 |
| QA-07 | 来源缺失问题 | 显示“当前图谱未提供出处” |
| QA-08 | 模型偶发失败 | 显示稳定降级，不暴露堆栈或密钥 |

### 5.2 图谱探索

| 编号 | 输入/操作 | 预期 |
| --- | --- | --- |
| EX-01 | 搜索四君子汤 | 返回方剂实体和基础信息 |
| EX-02 | 展开一跳邻居 | 返回组成药材和来源关系 |
| EX-03 | 只保留组成关系 | 其他关系被过滤 |
| EX-04 | 点击药材继续探索 | 以新实体为当前节点继续查询 |
| EX-05 | 查询多跳路径 | 高亮节点链、关系方向和逐跳证据 |
| EX-06 | 超过结果上限 | 显示限制提示，不渲染全图 |

### 5.3 实体对比

| 编号 | 输入/操作 | 预期 |
| --- | --- | --- |
| CP-01 | 对比麻黄与桂枝 | 展示共同属性和差异属性 |
| CP-02 | 对比麻黄汤与桂枝汤 | 展示共同药材和差异药材 |
| CP-03 | 无来源字段 | 对比表中明确标识 |
| CP-04 | 对比不存在的实体 | 请求澄清或返回稳定空状态 |

### 5.4 报告

| 编号 | 输入/操作 | 预期 |
| --- | --- | --- |
| RP-01 | 导出问答报告 | Markdown 包含问题、回答、证据、来源、审核、时间 |
| RP-02 | 导出对比报告 | 包含共同项、差异项和证据 |
| RP-03 | 检查敏感字段 | 不包含密钥、数据库信息和隐藏推理 |

### 5.5 Skill

| 编号 | Skill | 预期 |
| --- | --- | --- |
| SK-01 | 方剂组成核验 | 仅调用白名单工具，输出逐项核验 |
| SK-02 | 多跳关系取证 | 输出完整路径和审核结果 |
| SK-03 | 实体对比 | 返回结构化对比和来源 |
| SK-04 | 超过调用上限 | 安全终止并返回稳定原因 |

### 5.6 MCP

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| MC-01 | 列出 Resources | 返回 Schema、评测和使用说明 |
| MC-02 | 列出 Tools | 返回 5～7 个只读工具及 Schema |
| MC-03 | 调用实体解析 | 与 Web API 返回一致 EntityRef |
| MC-04 | 调用路径工具 | 返回 PathEvidence 和来源 |
| MC-05 | 非法参数 | 返回结构化参数错误 |
| MC-06 | 尝试任意 Cypher | 工具不存在或请求被拒绝 |

## 6. 安全验收

必须验证：

- 前端构建产物不包含 `.env`、模型 Key、Neo4j 密码、Redis 密码。
- 浏览器网络请求中不出现静态内部 API Key。
- Neo4j 使用只读账号。
- 用户参数只进入查询参数。
- 写操作、多语句、变量长度路径和未授权关系被拒绝。
- Markdown 渲染无法执行脚本。
- 图谱 SVG/Canvas 文本不会注入 HTML。
- 限流和每日预算在并发请求下仍有效。
- 日志不记录完整健康问题和模型提示词。

阻断级安全问题：

- 任意 Cypher 执行。
- 数据库写操作。
- 密钥泄漏。
- 跨会话读取。
- XSS 或任意 HTML 执行。

## 7. 性能验收

### 7.1 前端

| 指标 | 目标 |
| --- | --- |
| 首屏内容可见 | ≤ 2.5 秒 |
| 本地 UI 交互响应 | ≤ 300ms |
| 路由切换 | ≤ 500ms |
| 手机 Lighthouse 基础可用性 | 无阻断问题 |

### 7.2 API

| 指标 | 目标 |
| --- | --- |
| 固定演示问答 P95 | ≤ 15 秒 |
| 实体搜索 P95 | ≤ 2 秒 |
| 一跳邻居 P95 | ≤ 3 秒 |
| 2～3 步路径 P95 | ≤ 8 秒 |
| 报告生成 P95 | ≤ 5 秒 |

外部模型延迟单独记录，不与 Neo4j 查询耗时混淆。

### 7.3 演示容量

最低验证：

- 10 并发用户。
- 50 个连续固定问题。
- 一个会话完成 5 轮追问。
- 连续运行 24 小时。

## 8. 质量回归

### 8.1 自动化

- 当前 Python 测试不回归。
- 新增 Tool、Skill、API V2、MCP 测试通过。
- 前端单元、组件和 E2E 测试通过。
- OpenAPI 和 TypeScript 类型生成无未提交差异。

### 8.2 固定集

- 120 条黄金集接受门禁通过。
- 220 条产品固定集通过。
- 20 组 62 轮多轮集通过。
- 动态多跳固定集通过。
- 未知实体误召回率 `0%`。
- 无依据诚实率 `100%`。
- 来源缺失披露率 `100%`。

### 8.3 人工审核

- 完成 50 条独立领域人工事实审核。
- 事实正确率不低于 95%。
- 无依据断言数为 0。
- 来源披露正确率 100%。

外部模型故障期间，未执行项必须标记 `blocked` 或 `not_evaluated`，不得视为通过。

## 9. 浏览器验收

必须使用真实浏览器执行：

1. 首页加载和推荐场景。
2. 证据问答一轮。
3. 多轮追问一轮。
4. 图谱邻域探索。
5. 多跳路径展开。
6. 药材或方剂对比。
7. 报告导出。
8. 未知实体和无证据状态。
9. 手机视口。
10. MCP 说明页面和配置样例。

必须保存：

- 页面截图。
- 浏览器控制台无阻断错误。
- 网络请求无密钥。
- E2E 测试报告。

## 10. 部署验收

- `compose.demo.yml` 可在干净环境启动。
- 服务重启后数据仍在。
- 健康检查能区分 API、Redis 和 Neo4j 状态。
- Nginx 仅暴露 80/443。
- HTTPS 证书有效。
- 日志可定位 request_id 和错误类型。
- 每日模型预算达到后停止新增模型请求并给出降级提示。
- 回退上一镜像版本后服务可恢复。

## 12. 已知风险与豁免

以下情况不能直接豁免：

- 外部模型不稳定。
- 人工事实审核未完成。
- 安全阻断项。
- 数据来源无法披露。

可记录为观察项：

- 外部模型 P95 波动。
- 首次 BGE 加载时间。
- 单 worker 容量上限。
- 远程 MCP 未实现。
- 企业用户体系未实现。

## 13. 完成定义

只有满足以下条件才能宣布公开演示版 V1 完成：

- G0 至 G4 全部通过。
- G5 中除企业级延后项外的阻断项全部通过。
- 所有 P0 功能需求有对应验收结果。
- 没有未处理的安全阻断问题。
- 公开链接连续运行 24 小时。
- 文档中的当前状态与实际部署一致。
